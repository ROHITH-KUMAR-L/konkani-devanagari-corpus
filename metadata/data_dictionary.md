# Data dictionary

All text files are UTF-8, LF line endings, Unicode NFC. "Document tree" means `<root>/<category>/<doc_id>.txt`.

## Identifiers

| Field | Meaning |
|---|---|
| `doc_id` | Stable document id: `lit_*` / `cult_*` (book OCR), `edu_*` (textbook OCR), `news_<title>_<date>_<issue>` (e-paper issue), `ldcil_ko0000N` (LDC-IL gold), `wiki_gom_NN` (Wikipedia shard of about 1/20 of the articles) |
| `category` | One of `01_literature`, `02_news_media`, `03_education_science`, `04_culture_history`, `05_public_information`, `06_web_articles`, `07_oral_transcripts` |
| token | A word with punctuation removed; every number becomes `<NUM>` (`scripts/corpus_utils.py:tokenize`) |
| akshara | An orthographic syllable: a consonant cluster with its vowel sign and anusvara/visarga (`corpus_utils.aksharas`) |

## metadata/

| File | Columns |
|---|---|
| `sources.csv` | file, title, author_editor, publisher, year, category, subcategory, source_url, format, licence, collected_by, date_collected, notes. One row per source (books, textbook, e-paper title, LDC-IL, Wikipedia dump). Blank = not yet known |
| `documents.csv` | doc_id, category, source_type (`book_ocr`, `pdf_ocr`, `epaper_ocr`, `ldcil_gold`, `wikipedia`), source_path, title, tokens (iteration 0). Written by `extract_text.py` |
| `epaper_issues.csv` | title, issue_id, date, language, type, pages, pages_ocr, pages_text_layer, tokens, status, source_url, local_pdf. One row per newspaper issue (`fetch_epaper.py`) |
| `ldcil_sample_metadata.csv` | LDC-IL header fields per XML file (`extract_ldcil.py`) |
| `excluded_documents.csv` | file, reason, kept_instead. Hand-curated exclusions, skipped by `extract_text.py` |
| `quality_checks.csv` | doc_id, category, paragraphs_in, tokens_in, kok/mar/hin_markers, dropped_marathi/hindi/orthography/numeric (paragraphs), doc_dropped (0/1), invalid_token_rate, paragraphs_out, tokens_out (`validate_konkani.py`) |
| `dedup_log.csv` | doc_id, category, paragraphs_in, exact_duplicate_paragraphs, near_duplicate_of, jaccard_estimate, paragraphs_out (`deduplicate.py`) |

## data/

| Path | Content |
|---|---|
| `raw/<category>/` | Source files exactly as collected (never modified) |
| `interim/02_news_and_media/epaper/<TITLE>/<date>_<issue>.txt` | OCR text per issue; page-level files in the `<date>_<issue>/` folder |
| `interim/03_education_science/`, `interim/08_ldcil_gold_sample/` | OCR / extracted text of the textbook and LDC-IL files |
| `interim/iter0..iter3/` | Document trees per cleaning iteration (not in git; regenerated by `run_phase1.sh`). iter0 = raw; iter1–3 = one paragraph per line |
| `processed/by_category/<cat>/corpus_clean.txt` | Final paragraphs of that category, one per line |
| `processed/by_category/<cat>/sentences.tsv` | `doc_id`, `sent_id` (1-based within doc), `n_tokens`, `sentence` |
| `processed/combined/konkani_devanagari_clean.txt` | All final paragraphs |
| `processed/combined/sentences.txt` | One sentence per line |
| `processed/combined/sentences.tsv` | As the per-category TSV, all categories |
| `processed/combined/documents.jsonl` | `{"doc_id", "category", "text"}` per document (paragraphs separated by `\n`) |
| `splits/{train,dev,test}.txt` | One sentence per line, document-level split |
| `splits/split_manifest.csv` | doc_id, category, split, sentences, tokens |
| `eval/segmentation_gold.txt` | Development gold (40 paragraphs); sentence boundaries marked ` \|\| ` |
| `eval/segmentation_gold_heldout.txt` | Held-out gold (154 paragraphs), same format, never used to tune rules |
| `eval/language_audit_sample.tsv` | n, category, doc_id, label (`konkani`, `konkani_fragment`, `konkani_other_dialect_spelling`, `ocr_garbage`, `ocr_garbage_partial`, `non_konkani_hindi`, `non_konkani_unclear`); 200 rows, paragraph |

`data/processed/` and `data/splits/` are not in git (size and copyright). They are shared inside the team as a zip, or rebuilt with `scripts/run_phase1.sh`.

## results/

| File | Columns / content |
|---|---|
| `corpus_statistics.txt`, `stats.json` | Tokens, types, TTR, root TTR, hapax/dis legomena, token composition (deva/num/latin/other), Zipf slope, Heaps K and β, coverage, per-category table, top 30 types |
| `word_frequencies.csv` | rank, type, freq, rel_freq (freq/N), cum_coverage (share of tokens covered by ranks 1..rank) |
| `coverage_analysis.csv` | scope (`overall` or category), coverage_pct, types_needed, pct_of_vocabulary |
| `category_statistics.csv` | category, documents, tokens, share_of_corpus, types, ttr, root_ttr, hapax, hapax_ratio_types, deva/num/latin/other_share |
| `iter0/`, `iter1/`, `iter2/` | The same files for earlier iterations (top-level `results/` = final, iteration 3) |
| `document_audit.csv` | doc_id, category, tokens_iter0..iter3, kept_pct |
| `segmentation_eval.txt`, `segmentation_eval_heldout.txt` | Boundary TP/FP/FN, precision, recall, F1, system output for paragraphs with errors (dev / held-out gold) |
| `length_analysis.txt` | Sentence- and word-length summary |
| `sentence_length_stats.csv` | scope, sentences, mean, std, min, max, p5, p25, p50, p75, p95, p99 |
| `sentence_length_distribution.csv` | n_tokens, sentences |
| `word_length_distribution.csv` | length, chars_token_weighted, chars_type_weighted, aksharas_token_weighted, aksharas_type_weighted (counts) |
| `plots/` | zipf.png, heaps.png, coverage.png, sentence_length.png, word_length.png |
| `ocr_quality/` | OCR CER/WER summary, per-paragraph scores, character confusions (`ocr_quality_check.py`) |
